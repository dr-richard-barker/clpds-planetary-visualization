\section*{Data Availability}
All raw scientific data products analyzed in this work are accessible via China's Lunar and Planetary Data Release System (CLPDS) hosted by the National Astronomical Observatories, Chinese Academy of Sciences (NAOC / CNSA) at \url{https://clpds.bao.ac.cn}. The calibrated JSON datasets, spectral libraries, and radar profiles generated in this study are archived on Zenodo (\href{https://doi.org/10.5281/zenodo.XXXXXXX}{DOI: 10.5281/zenodo.XXXXXXX}) and hosted on GitHub (\url{https://github.com/dr-richard-barker/clpds-planetary-visualization}).

\section*{Code Availability}
The full source code for the data processing pipelines, calibration scripts, and interactive WebGL/Three.js visualization suite is open source under the MIT License at \url{https://github.com/dr-richard-barker/clpds-planetary-visualization}.
